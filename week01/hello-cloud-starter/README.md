# Hello Cloud Starter

클라우드 컴퓨팅 수업 1주차 실습용 기본 프로젝트입니다.

## 실습 목표

- GitHub 저장소를 내 계정으로 복사한다.
- 프로젝트를 clone한다.
- 메인 페이지의 문구를 수정한다.
- GitHub에 commit/push한다.
- Vercel에 배포한다.
- 코드를 수정하면 자동으로 다시 배포되는 것을 확인한다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:3000
```

## 수정할 파일

```text
app/page.js
```

`Hello Cloud!` 문구를 나만의 문장으로 바꿔보세요.

예:

```text
Hello Cloud!
My first deployment is live.
```

## GitHub에 올리지 말아야 할 것

다음은 절대 올리면 안 됨:

```text
node_modules/
.next/
.env
.env.local
.vercel/
```

## 1주차 실습 과제

```text
1. 강의 starter repository를 내 GitHub 계정으로 복사한다.
2. 내 컴퓨터에 clone한다.
3. app/page.js 파일의 Hello Cloud! 문구를 자기 이름이나 문장으로 바꾼다.
4. 변경 내용을 commit하고 push한다.
5. Vercel에 배포한다.
6. 배포된 URL을 제출한다.
```
